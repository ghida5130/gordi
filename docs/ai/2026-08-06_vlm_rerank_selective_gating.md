# VLM 리랭크 선택적 적용 — 구현 이유 검증 (2026-08-06)

- 결정: **기본 ON 유지 + 관측된 무가치 국면만 스킵하는 키워드 게이트 v1**
- 근거 데이터: 팀 블라인드 A/B 라운드 (6명 × 12쿼리 = 72표,
  `eval/baselines/2026-08-06-vlm-ab-onoff-results.json`) +
  검색 모호도 오프라인 분석 (본 문서 §3)
- 상태: 사용자 승인 후 구현 (`RECOMMENDATION_VLM_RERANK_MODE`)

## 1. 배경 — 왜 "전면 ON"을 재검토하는가

A/B 라운드 집계: ON 승 35 / OFF 승 19 / 무승부 18.
ON 승률 64.8%(무승부 제외, sign test 양측 p≈0.03)로 리랭크의 품질
기여는 통계적으로 유의하다. 그러나 평균 지연이 ON 10.7s vs OFF
0.6s(**17배**)이고, 무승부가 25%라 "모든 쿼리에 10초를 쓰는 것"의
효율이 의심됐다.

쿼리별 순이득(net = ON승 − OFF승):

| 쿼리 | net | 비고 |
|---|---:|---|
| 루프탑 데이트 | **+5** | 심미·코디 민감 |
| 피크닉 | +3 | |
| 러닝 하의 | +3 | 무 3, ON 무패 |
| 첫 출근 | +2 | |
| 겨울 데이트 | +2 | |
| 여름 여행 | +2 | |
| 캠퍼스 데일리 | +1 | **무 5** — 사실상 무차이 |
| 명절 | +1 | |
| 하객 하의 | 0 | 3:3 |
| 페스티벌 | 0 | 2:2:2 |
| 소개팅 | −1 | |
| 면접 | **−2** | 무 4 — OFF가 오히려 선호 |

## 2. 가설과 검증 — 무엇이 리랭크 가치를 예측하는가

### 가설 A: "검색이 확신하는 쿼리에선 리랭크가 무의미" → **기각**

TPO 태그 임베딩 도입 후 격식 쿼리(면접)에서 리랭크가 무가치해진
관찰에서, "검색 점수가 확실히 갈리면(낮은 모호도) 리랭크를 스킵할
수 있다"는 게이트 가설을 세웠다. 12개 쿼리를 리랭크 OFF
파이프라인으로 재실행해 상위 10건 점수 분포를 측정하고 net과
상관을 계산했다:

| 모호도 지표 | net과 스피어만 상관 |
|---|---:|
| 최종 점수 표준편차 | 0.096 |
| top1−top10 점수 갭 | 0.127 |
| 검색 점수 표준편차 | −0.032 |

**상관 없음.** 예: 첫 출근은 점수 갭이 가장 컸지만(0.174) net +2로
리랭크가 이겼고, 면접은 갭이 평범한데 리랭크가 졌다. 검색 신뢰도
기반 게이트는 데이터가 지지하지 않으므로 채택하지 않는다.
(이 기각이 본 문서의 존재 이유다 — 그럴듯한 자동 게이트를
구현하기 전에 검증했고, 틀렸음을 확인했다.)

### 가설 B: "국면(occasion)이 가치를 가른다" → 부분 지지

net ≤ 0 쿼리(면접, 하객, 소개팅, 페스티벌)와 무승부 지배
쿼리(캠퍼스, 무 5/6)는 두 부류로 묶인다:

1. **격식 행사·사무 국면** (면접 −2, 하객 0): TPO 태그 임베딩이
   격식 신호를 이미 검색 단계에서 흡수 — 리랭크가 고칠 것이 없다.
2. **데일리 국면** (캠퍼스 +1, 무 5): 어떤 무난한 옷이든 정답 —
   심미 재정렬의 변별력이 없다.

반면 심미·코디 뉘앙스가 갈리는 국면(데이트 +5/+2, 피크닉 +3,
여행 +2)에서 리랭크가 일관되게 이겼다.

## 3. 결정 — 스킵 사전 기반 게이트 v1

- **기본값은 리랭크 ON 유지** (전체 승률 64.8%가 유의하므로,
  이기는 걸 끄는 위험을 지지 않는다).
- 질의 텍스트(무드+TPO 합성문)가 **관측된 무가치 국면의 키워드**에
  걸리면 리랭크 스킵:
  - 격식 행사·사무: 면접, 정장, 결혼식, 하객
  - 데일리: 매일, 데일리, 일상, 등교, 통학, 학교
- **이미지 쿼리는 게이트를 우회하고 항상 리랭크** — 이미지 입력은
  그 자체가 심미 맥락 신호다.
- 설정: `RECOMMENDATION_VLM_RERANK_MODE=selective|always`
  (기본 selective). `RECOMMENDATION_VLM_RERANK_ENABLED`는 기존대로
  마스터 스위치. A/B 데모의 ON 팔은 always 고정(게이트 비교 오염
  방지).

### 예상 효과 (A/B 실측 기준 추정)

- 12쿼리 중 3개(면접·하객·캠퍼스) 스킵 → 리랭크 호출 ~25% 절감
- 품질 net: +18 → **+19** (면접에서 OFF가 선호였으므로 스킵이
  오히려 +2, 캠퍼스 +1 상실, 하객 0)

### 한계와 감시 항목 (정직성 조항)

- **쿼리당 n=6**이라 개별 net은 잡음이 크다. 스킵 사전은 관측된
  국면의 키워드로 시작하는 명시적 선택이며, 12개 점에 대한
  과적합 위험을 인정한다. 그래서 사전은 좁게 시작한다(net ≤ 0
  중에서도 소개팅·페스티벌은 단일 관측이라 **제외** — 감시 항목).
- 게이트 적용 후 같은 A/B 데모로 재라운드를 돌리면 게이트 자체의
  효과를 같은 방법으로 검증할 수 있다(스킵 국면에서 OFF와 동률
  이상인지).
- 롤백: `RECOMMENDATION_VLM_RERANK_MODE=always` 한 줄.
