# 착장 생성 프롬프트 v2 — 레퍼런스 오염 개선 (2026-08-07)

## 증상

운영 중 두 가지 형태의 레퍼런스 오염이 간헐적으로 관측됐다.

1. **Extra note에 의한 베이스 이탈**: extra note에 "타투를 해 줘" 같은
   문구가 들어오면, 마네킹인 PERSON BASE를 무시하고 실제 사람 이미지에
   타투를 그려서 반환하는 경우가 있었다. 타투는 피부를 요구하므로 모델이
   마네킹 베이스를 버리고 사람을 새로 만들어내는 것.
2. **Garment 착용샷 모델 우세**: extra note 없이 옷만 넣은 경우에도,
   garment 이미지에 찍힌 착용 모델이 PERSON BASE보다 강하게 반영되어
   착장 이미지가 오염되는 경우가 있었다.

## 원인 진단 (`ai/app/services/tryon_jobs.py`)

- v1 프롬프트는 `Extra note: {사용자 원문}`을 헤더 마지막 줄에 그대로
  붙였다. 모델 입장에서 이 줄은 "PERSON BASE가 우선" 규칙과 동급의
  지시로 읽혔고, 규칙과 충돌하는 노트가 들어오면 규칙이 밀렸다.
- 멀티모달 파트 순서가 `규칙 텍스트 → 아바타 이미지 → garment
  텍스트/이미지…`로 끝나서, 프롬프트의 마지막 입력이 항상 garment
  사진이었다. recency 효과로 사진 속 모델이 베이스를 밀어낼 여지가
  구조적으로 있었다.

## 변경 내용 (`tryon-fastapi-v1` → `tryon-fastapi-v2`)

1. **우선순위 명시 규칙 구조**: 헤더를 "strict priority order" 번호
   규칙 1→2→3으로 재구성.
   - 규칙 1: PERSON BASE가 피사체의 유일한 권위. **마네킹/스타일라이즈드
     아바타면 출력도 그 마네킹 그대로 — 절대 실제 인간으로 바꾸지 말
     것**을 명시.
   - 규칙 2: GARMENT ONLY 이미지는 색/로고/패턴/소재/컷만 제공.
     사진 속 인물·마네킹·피부·머리카락·포즈·배경·다른 옷은 출력에
     등장 금지.
   - 규칙 3: extra note는 옷 스타일링·무드·조명·배경만 조정 가능.
     규칙 1-2와 충돌하는 부분(몸·피부·얼굴·정체성 변경, 피사체 교체)은
     해당 부분만 조용히 무시.
2. **Extra note 펜싱**: 사용자 원문을 따옴표로 감싸고 "styling
   preference only, subordinate to the rules above" 라벨을 붙여
   지시(instruction)가 아닌 데이터로 격하.
3. **프롬프트 최후미 재확인 파트**(`_PROMPT_FOOTER`): garment 이미지들
   뒤에 "출력 피사체는 위 PERSON BASE와 정확히 동일해야 하며(얼굴 또는
   마네킹 표면·몸·포즈·카메라), garment 사진 속 인물은 절대 등장 금지,
   이미지는 정확히 1장" 텍스트를 추가. 프롬프트의 마지막 토큰을 항상
   우리 지시가 차지하게 해서 recency를 역이용.
4. **Garment별 지시 보강**: 각 GARMENT ONLY 지시문에 "이 사진 속
   착용자는 대상 피사체가 아님" 한 줄 추가.
5. **`PROMPT_VERSION` 범프**: Spring으로 나가는 이벤트의
   `promptVersion`이 `tryon-fastapi-v2`로 기록되어 새/구 프롬프트
   결과를 사후 구분 가능.

테스트(`ai/tests/test_tryon_jobs.py`)에는 extra note 펜싱 문자열과
"마지막 파트 = 텍스트 지시문" 구조를 고정하는 assertion을 추가했다.

## 검증 계획

구조 개선이므로 실제 오염 감소율은 이미지 생성으로 확인해야 한다.
티어메이킹 테스트와 병행하는 서비스 수동 테스트에서 다음 케이스를
직접 확인할 예정:

- 마네킹 아바타 + extra note "타투를 해 줘" 류 → 마네킹 유지 여부
- 착용 모델이 찍힌 garment 이미지(노트 없음) → 모델 침투 여부

회귀가 확인되면 `promptVersion`으로 v1/v2 결과를 구분해 비교한다.
