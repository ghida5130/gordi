## 2. 세션 분할 제안 (야간 3~4회)

우선순위 = 빈 셀부터. 한 세션이 끊겨도 `--skip-existing` 덕에 이어서
실행하면 된다.

1. **1일차 — 아우터 전부** (남녀 블레이저·재킷·코트·패딩·카디건·
   플리스·바람막이, ~2,450 raw): 현재 0인 최대 공백.
2. **2일차 — 포멀·니트·스커트/원피스** (셔츠/블라우스·니트·슬랙스·
   스커트·원피스, ~2,900 raw).
3. **3일차 — 데일리·스포티 보강** (맨투맨·후드·긴소매·피케·데님·코튼·
   트레이닝·스포츠레저, ~4,000 raw).
4. **4일차 — 잔여분·부족 셀 재수집** (검증 후 INVALID로 빠진 만큼).

## 3. 세션 후 처리 (매 세션 반복)

```bash
# 1. 정규화 + 검증
python -m garment_collector validate --dataset-root garment_dataset-v2

# 2. VLM 자동 검수 (레퍼런스 타입 판정, effort low 고정)
python -m garment_collector review-images --dataset-root garment_dataset-v2 \
  --reasoning-effort low

# 3. 셀 요약 리포트 갱신
python scripts/summarize_dataset_cells.py
```

- `review-images`는 멱등(이미 검수된 항목 skip)이므로 실패분은 같은
  명령 재실행으로 회복한다. 빈 응답 실패가 반복되면 effort를 low로
  유지한 채 재실행 (2026-08-02 트러블슈팅 참조).
- 이미지·데이터셋·리포트는 **Git에 절대 커밋하지 않는다.**
