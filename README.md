# 고르디 (Gordi)

> AI가 취향에 맞는 옷을 추천하고, 친구들과 함께 비교하며 고를 수 있도록 돕는 패션 의사결정 서비스

고르디는 수많은 상품 사이에서 무엇을 골라야 할지 고민하는 과정을 줄여 줍니다. 사용자의 카테고리, 예산, 선호 무드와 프로필을 바탕으로 어울리는 상품을 추천하고, 아바타 가상 피팅으로 착장 이미지를 미리 확인할 수 있습니다. 혼자 결정하기 어렵다면 친구를 초대해 실시간 공동 티어메이커에서 후보를 정리하고 최종 상품을 함께 선택할 수 있습니다.

## 주요 기능

### 맞춤형 프로필과 아바타

- 성별과 선택 입력인 키·몸무게 범주, 체형을 바탕으로 사용자 아바타를 구성합니다.
- 체형 상세 입력을 생략하면 성별에 맞는 표준 아바타를 제공합니다.
- 프로필과 아바타는 마이페이지에서 다시 수정할 수 있습니다.

### AI 상품 추천

- 상의, 하의, 아우터, 원피스/세트, 신발, 가방 중 원하는 카테고리를 선택합니다.
- 예산 범위와 여러 개의 선호 무드 태그를 추천 조건으로 사용할 수 있습니다.
- 상품 이미지와 설명, 카테고리의 임베딩 유사도에 규칙 기반 점수와 VLM 재정렬을 결합해 후보를 추천합니다.
- 마음에 들지 않는 상품만 골라 새로운 후보로 다시 추천받을 수 있습니다.

![AI 상품 추천 파이프라인](docs/images/추천파이프라인.png)

### AI 가상 피팅

- 아바타 프로필과 선택한 의상을 조합해 가상 착장 이미지를 생성합니다.
- 사용자의 체형 정보와 의상 카테고리를 바탕으로 착용 방식을 반영합니다.
- 생성 결과를 방 참여자들과 공유하고 세션 결과에 저장할 수 있습니다.

> 가상 피팅 이미지는 상품 비교를 돕기 위한 시각화이며 실제 신체 치수나 핏을 보장하지 않습니다.

![AI 가상 피팅 파이프라인](docs/images/가상피팅파이프라인.png)

### 친구와 같이 고르기

- 추천 상품을 후보로 등록해 최대 6명이 참여하는 방을 만들고 초대 링크를 공유합니다.
- 참여자 현황과 공동 보드는 실시간으로 동기화됩니다.
- 모든 참여자가 상품을 S·A·B 등의 티어로 분류하고 티어 안의 순서를 함께 조정합니다.
- 음성 대화를 이용하며 후보를 비교하고, 최종 상위 상품을 확정할 수 있습니다.

### 결과와 기록

- 확정된 상위 1~3개 상품의 이미지, 브랜드, 상품명, 가격과 순위를 확인합니다.
- 판매처 링크가 있는 상품은 외부 구매 페이지로 이동할 수 있습니다.
- 회원은 이전 선택 결과와 당시의 상품 정보, 추천 조건을 내 기록에서 다시 확인할 수 있습니다.

## 서비스 화면

### 1. 메인 페이지

고르디의 핵심 기능인 체형 설정, AI 의상 추천, 티어메이커로 이동할 수 있는 시작 화면입니다. AI 추천과 친구들의 공동 평가, 가상 피팅으로 이어지는 서비스 경험을 한눈에 확인할 수 있습니다.

![고르디 메인 페이지](docs/images/1_메인페이지.png)

### 2. 시작 방식 선택

새로운 의상을 추천받아 티어메이커 방을 만들거나, 친구가 공유한 방 코드를 입력해 기존 방에 참여할 수 있습니다.

![고르디 시작 방식 선택 화면](docs/images/2_지금시작하기.png)

### 3. 의상 추천 조건 입력

카테고리와 세부 분류, 예산, 선호 무드를 선택하고 필요한 경우 TPO를 자연어로 입력합니다. 입력한 조건은 사용자에게 맞는 의상 후보를 탐색하고 정렬하는 데 사용됩니다.

![AI 의상 추천 조건 입력 화면](docs/images/3_의상추천옵션.png)

### 4. AI 의상 추천 결과

추천된 상품의 이미지, 브랜드, 상품명, 가격과 카테고리를 카드 형태로 비교할 수 있습니다. 전체 추천을 다시 받거나 마음에 들지 않는 상품만 선택해 교체한 뒤, 현재 후보를 가지고 티어메이커로 이동할 수 있습니다.

![AI 의상 추천 결과 화면](docs/images/4_의상추천결과.png)

### 5. 티어메이커 대기실

방 코드나 초대 링크를 친구에게 공유하고 참여 현황과 접속 상태를 실시간으로 확인합니다. 참여자가 모이면 방장이 공동 티어메이킹을 시작합니다.

![티어메이커 대기실](docs/images/5_티어메이킹대기실.png)

### 6. 공동 티어메이커와 가상 피팅

참여자들이 추천 상품을 티어 사이로 드래그해 함께 순위를 정합니다. 동시에 피팅 후보와 카테고리별 의상을 선택하고 착용 방식이나 추가 요청을 입력해 AI 가상 피팅 이미지를 생성할 수 있으며, 음성 연결을 통해 의견을 나눌 수 있습니다.

![공동 티어메이커 방](docs/images/6_티어메이킹방.png)

### 7. 티어메이킹 결과

방 종료 시 확정된 티어와 티어 내 순서를 기준으로 전체 순위를 표시합니다. 공동 선택 과정에서 마지막으로 확정한 가상 피팅 결과도 함께 확인할 수 있습니다.

![공동 티어메이커 결과 화면](docs/images/7_티어메이킹결과.png)

### 8. 마이페이지 프로필

추천과 가상 피팅에 활용되는 사용자 프로필과 아바타, 체형 정보를 확인하고 수정할 수 있습니다.

![마이페이지 프로필 화면](docs/images/8_마이페이지.png)

### 9. 마이페이지 기록

완료된 티어메이커 세션과 당시 확정된 상위 상품을 모아 봅니다. 각 기록의 상세 화면으로 이동해 최종 순위와 상품 정보를 다시 확인할 수 있습니다.

![마이페이지 티어메이커 기록 화면](docs/images/9_마이페이지2.png)

## 시스템 아키텍처

## 로컬 Docker 실행

> Docker 이미지 빌드에는 시간이 걸릴 수 있습니다. 평소에는 각 서비스를 로컬에서 개발하고, 통합 확인이 필요할 때 Docker 환경을 사용하는 것을 권장합니다.

### 데이터베이스 실행

```bash
docker compose up -d
```

### 애플리케이션 실행

전체 서비스를 한 번에 실행합니다.

```bash
docker compose -f docker-compose.local.yml up -d --build
```

필요한 서비스만 개별적으로 실행할 수도 있습니다.

```bash
docker compose -f docker-compose.local.yml up -d --build frontend
docker compose -f docker-compose.local.yml up -d --build backend
docker compose -f docker-compose.local.yml up -d --build ai
docker compose -f docker-compose.local.yml up -d --build nginx
```

여러 서비스를 함께 지정할 수도 있습니다.

```bash
docker compose -f docker-compose.local.yml up -d --build backend ai
```
