# MUSINSA demo test data

이미지 생성 모델의 내부 비교 데모를 위한 소량의 상·하의 세트다. `manifest.json`에 캡션, 핏 태그 2~3개, 상품 페이지와 이미지 출처를 함께 기록한다.

- 6개 테스트 케이스, 12개 상품 이미지
- 이미지 해상도: 너비 1200px
- `product-only`: 단독 상품 컷
- `worn-reference`: 모델 착용 컷 또는 다른 착장 일부가 함께 보이는 컷

`worn-reference`는 모델이 참고 이미지 속 인물이나 다른 의상을 따라갈 수 있으므로 단독 상품 컷과 결과를 분리해서 해석한다. 이 데이터는 팀 내부 데모에만 사용하고, 외부 배포·학습 데이터 전환 전에는 무신사와 브랜드의 이미지 이용 권리를 별도로 확인한다.

프론트에서 테스트 세트를 선택하고 `샘플 불러오기`를 누르면 이미지, 한 줄 캡션, 핏 태그가 입력 폼에 자동으로 채워진다. 아바타는 케이스와 체형을 분리해 비교할 수 있도록 자동 선택하지 않는다.

## 2차 파일럿

`round2-manifest.json`은 사이즈 실측 기반 프롬프트와 착용컷 인물 오염을 검증하는 6개 단일 의류 케이스와, 실제 사용 비중이 높은 상·하의 조합 6개 케이스를 함께 담는다.

- `SIZE_SENSITIVITY` 4개: 동일 상품 이미지·아바타에서 선택 사이즈와 실측 행만 변경
- `REFERENCE_CONTAMINATION` 2개: 동일 상품·사이즈·아바타에서 단독컷과 인물 포함컷만 변경
- `OUTFIT_COMBINATION` 6개: 여성 3개·남성 3개, 각 케이스에 `TOP`과 `BOTTOM`을 함께 입력
- 여성 하의 범위: 부츠컷, 파라슈트, 와이드 슬랙스
- 신체 입력: 성별, 키, 몸무게, 사전제작 아바타 ID
- 의류 입력: 슬롯, 선택 사이즈, 단면·길이 실측, 레퍼런스 유형
- 재현성: 각 로컬 이미지의 SHA-256과 원본 상품·이미지 URL 보존

2차 데이터 역시 `internal-evaluation-only-unverified` 상태다. 외부 공개, 재배포 또는 모델 학습 용도로 전환하기 전에 이미지 권리를 별도로 확인한다.
