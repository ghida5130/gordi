## [Part 1] 기술 기반 아이디어 발산 (WebRTC 중심 브레인스토밍)
초기 기획 단계에서 실시간 통신 기술(WebRTC), 인공지능(AI), 그리고 실제 비즈니스·사회적 효용성을 접목하여 제안했던 핵심 아이디어 메인후보군입니다.

### 01. 실시간 보이스피싱 탐지 시스템
* **문제 정의:** 보이스피싱 피해가 급증함에도 기존 앱들은 사후 번호 필터링에 의존하여 통화 중 실시간 사기 대응에 한계가 있음.
* **해결 방안:** WebRTC 기반 통화 스트림 상에서 딥러닝 기반으로 사기 정황을 실시간 포착·차단하는 솔루션 구현.
* **핵심 기능:** 신분증 객체 탐지 시 실시간 화면 Blur 처리 및 민감 정보 노출 제어.

### 02. 실시간 졸음운전 시, 경고 서비스
* **문제 정의:** 운전 중 발생하는 하품, 시선 이탈 등 졸음운전 전조증상을 실시간으로 면밀히 감지하고 원격에서 선제적으로 예방 및 경고 알림을 줄 안전 장치가 부족함.
* **해결 방안:** 운전자 전면 카메라 피드를 분석하여 위험 정황을 탐지하는 즉시 운전자에게 알림을 제공하고, 보호자(가족)에게 WebSocket/FCM 실시간 경고 푸시를 보내 WebRTC 음성 연결을 활성화하는 안심 드라이빙 케어.
* **핵심 기능:** 운전자 상태 감지(졸음, 하품, 휴대폰 사용 등), 백엔드(Spring Boot) 내 위험 이벤트 기록 및 보호자 실시간 푸시·음성 송출 연동.

### 03.실시간 소셜파티 화상 게임
* **문제 정의:** 기존 화상회의 솔루션은 단순 업무용 인터페이스에 국한되어 이를 레크리에이션이나 소셜 활동 콘텐츠로 확장하여 몰입하기 어려움.
* **해결 방안:** 화상회의 자체를 게임 콘텐츠 무대로 삼아, 참가자 간의 비대칭 영상 송출 환경 내에서 AI가 참가자들의 미세한 얼굴 보정 변화, 제스처, 표정을 정교하게 트래킹하여 승패나 미션을 실시간 판정하는 소셜 파티 게임.

### 04. 실시간 분리수거 자막 서비스
* **문제 정의:** 복합 소재 플라스틱 등 분리배출 재질 판단이 모호하여 실제 가정 내에서 잘못 배출하는 사례가 많음.
* **해결 방안:** 가족들이 화상으로 함께 확인하며, 카메라에 비춰진 쓰레기의 재질을 YOLO 객체 인식 기반으로 판별하여 화면에 시각적으로 매핑해 주는 플랫폼.
* **차별 철학:** AI가 "여기에 버려라"라고 직접 지시하지 않고 "PET", "비닐", "유리" 등 재질 정보만 시각적으로 오버레이하며, 최종 의사결정은 사용자가 내리는 구조 설계 (얼굴 영역 자동 블러 처리로 프라이버시 보호).

### 05. 실시간 화상 발표 인터랙티브 발표 툴
* **문제 정의:** 비대면 원격 발표 진행 시 마우스나 키보드 제어로 인해 발표자의 자연스러운 시선 처리가 끊기고, 청중과의 실시간 인터랙션 집중도가 분산됨.
* **해결 방안:** 발표자 웹캠 영상에서 손가락 및 손바닥 랜드마크를 추적하고 제스처(페이지 넘기기, 움켜쥐기 등)를 인식하여, 화면 공유 중인 PPT 슬라이드를 제어하고 레이저 포인터를 오버레이하는 인터랙티브 발표 툴.
* **핵심 기능:** 실시간 손동작 인식 기반 프리젠테이션 제어, 검지손가락 끝을 인식한 가상 레이저 포인터 및 실시간 드로잉.

### 06. 옛추억 플랫폼
* **문제 정의:** 조부모 및 고령층 세대와 비대면 소통 시, 흥미로운 화제나 공감대를 형성할 매개체가 부족하여 통화 몰입도가 떨어짐.
* **해결 방안:** 고령층 사용자가 보유한 옛날 흑백 사진을 실시간 컬러 복원 기술로 선명하게 되살려내고, 이를 가족 간 WebRTC 영상 통화 화면에 공유하여 다 함께 옛 추억을 나누는 상호작용 플랫폼.
* **차별 철학:** AI는 복원 생성 기술만 보조하고, 세대 간 따뜻한 감정 교류와 깊은 대화는 사용자들이 온전히 주도하도록 유도.

### 07.  비대면 아이웨어 컨설팅
* **문제 정의:** 안경테 온라인 구매 시 착용감과 안면 사이즈 피팅 상태를 가늠하기 어려워 반품률이 매우 높음.
* **해결 방안:** Face Landmark 기반으로 안구 거리(PD)를 실시간 측정하고 안경 3D 모델을 얼굴 정면에 매핑하여, 안경사가 실시간으로 피팅 각도와 상태를 함께 모니터링하며 상담해 주는 컨설팅 플랫폼.
* **핵심 기능:** 실시간 안경 AR 피팅 및 렌즈 색상 가상 변경, 안경사의 원격 화면 제어를 통한 안경 위치 미세 조정.

## [Part 2] 1차 기획안 설계 (보안 특화 실시간 금융사기 방지 '보이스피싱방지웹')

## 1. 기획의도

### 기존 보이스피싱 방지 서비스의 한계 및 최근 수법 변화

기존의 보이스피싱 차단 앱(후후, T전화 등)은 **사후 신고된 블랙리스트 전화번호 DB**에 의존합니다. 그러나 최근 사기 수법은 대포폰 변작, 메신저 피싱으로도 진화했습니다.
피해자가 인지하지 못한 상태에서 금융기관 상담을 가장해 이루어지는 사기를 막기 위해서는 **'통화 내용과 화면 행위'에 대한 실시간 분석**이 필요하다고 생각했습니다.

## 2. 서비스 요약

### 1) 서비스 소개

 금융기관 비대면 상담 및 인앱 통화 시, WebRTC 오디오/비디오 스트림을 실시간으로 캡처하여 보이스피싱 시나리오, 딥페이크 등을 분석하고 위험 시 3자(가족/보호자/관제 시스템)에게 즉각 알림 및 LLM 에이전트 개입을 지원하는 **실시간 보안 스트리밍 솔루션**입니다.

### 2) 서비스 프로세스 및 AI 분석 흐름 (Flow)

```
[사용자 (PWA/웹)] ──(WebRTC 연결)──> [금융기관 / 상담사 / 인앱 채널]
       │
       ├── (음성 스트림 분기) ──> [Faster-Whisper (STT)] ──> [KoBERT (피싱 분류)] ──> 위험도 적립
       │                                              └──> [LLM Agent (시나리오 검증)] ──> 위험 경고
       │
       ├── (음성 특징 추출) ──> [Wav2Vec2 (감정/압박 분석)] ──────────────────────────────> 떨림/호흡 인지
       │
       ├── (영상/화면 스트림) ─> [PaddleOCR (문서/링크 분석)] ────────────────────────────> 위조공문 탐지
       │                                              └──> [YOLOv11 (원격제어/이상행동)] ──> 위험 화면 감지
       │
       └── [종합 위험도 Score Fusion]
                     │
            (위험 점수 Threshold 초과)
                     │
                     ├─> [화면 UI] 강제 경고 팝업 및 통화 차단 안내
                     ├─> [LLM 에이전트] 상담사 화면에 대응 가이드라인 실시간 팝업
                     └─> [Web Application Server] 보호자에게 SMS/FCM 위험 알림 발송
```

## 3. 페르소나 (타겟층)

### 페르소나 1: 고령층 (디지털 취약계층)

- **이름 / 나이 / 직업**: 김복순 (72세) / 은퇴 후 전업주부
- **디지털 활용 수준**: 낮음 (카카오톡 메시지 확인 및 유튜브 시청 수준, 금융 앱 사용 미숙)
- **금융사기 위험 요소**: 자녀 사칭 메신저 피싱, 검찰 사칭 "계좌가 범죄에 연루되었다"는 압박 전화에 취약함.
- **서비스가 필요한 이유**: 사기꾼의 지시대로 금융사 웹 상담 페이지에 접속했을 때 본인도 모르게 당하는 것을 방지.
- **가장 많이 사용할 기능**: **온디바이스 음성 감정 분석(심리 압박 탐지) 및 가족 알림 기능**.

### 페르소나 2: 금융기관 비대면 전담 상담사

- **이름 / 나이 / 직업**: 박진아 (34세) / OO은행 비대면 대출 심사 상담원
- **디지털 활용 수준**: 상 (업무용 대시보드 및 다중 모니터, CRM 시스템 능숙 활용)
- **금융사기 위험 요소**: 고객이 통화 중 사기꾼에게 조종당하고 있음을 인지하지 못하고 대출을 강행하는 상황 방관 위험.
- **서비스가 필요한 이유**: 상담 도중 고객의 음성 톤이나 답변 내용에서 피싱 징후를 시스템이 대신 포착해 주어야 함.
- **가장 많이 사용할 기능**: **LLM 에이전트 개입 및 위험도 Score 대시보드 실시간 표출**.

## 5. 리스크 관리: 오판단(False Positive) 시 대책

AI 모델이 정상적인 은행 상담원이나 실제 검사의 통화를 피싱으로 오판단하여 금융 거래를 막아버릴 경우, 고객의 불편과 금융사의 민원이 폭증할 수 있습니다.

- **1단계: 실시간 팩트체크 리포트 팝업 (차단 전 단계)**
    - AI가 무조건 통화를 끊는 것이 아니라, "검찰", "안전계좌" 등의 키워드가 인식되면 화면에 [실시간 팩트체크 팝업]을 띄웁니다.
    - *팝업 내용 예시*: "현재 발신된 번호는 대검찰청 공식 번호(02-3480-XXXX)와 일치하지 않는 인터넷 전화 변작 번호입니다. 또한 정부 기관은 카카오톡으로 공문을 보내지 않습니다." 이를 통해 유저가 스스로 판단할 수 있는 근거를 먼저 제공합니다.
- **2단계: '소액 인증'을 통한 잠금 해제**
    - 오탐으로 인해 출금이나 대출 세션이 일시 정지된 경우, 미리 등록된 **가족(보호자)의 동의 승인**이 있거나, 생체인증(Face ID 등) 및 기존 지정 계좌를 통한 1원 인증을 거치면 즉시 잠금이 해제되도록 '세이프티 밸브'를 설계합니다.

## [Part 3] 최종 기획 피벗 및 구체화 (2D 마네킹 패션 플랫폼 '고르디')
최종 프로젝트 주제인 '고르디' 서비스의 완성도를 높이기 위해, 실시간 네트워크 환경과 외부 데이터 종속성 문제를 고려한 상세 기능 요구사항을 작성하고 관리함.

최종 결과 화면 핵심 기능 동작을 중심으로 중요도에 따라 P0(필수 기능)와 P1(선택/확장 기능)으로 세분화하여 리소스 관리 체계를 다듬음.

예외 상황 처리 기준 설계:
외부 쇼핑몰의 실시간 재고/가격 변동으로 발생할 서비스 불일치를 방지하기 위해 '상품 수집 정보 기준 시각'을 화면에 필수적으로 노출하도록 명세함.
외부 구매 페이지 링크 연결 시 웹 브라우저 팝업 차단 설정으로 인한 유실을 막기 위해 직접 이동 대체 UI 제공 예외 조건을 추가함.
'이전 추천 조건 복제(F-06-04)' 시, 품절 상품이 발생한 경우의 실시간 대체 추천 API 재호출 트리거 정책을 세부 명세로 추가함.

## [Part 4] 프로젝트 기획 산출물 요약
프로젝트의 초기 아이디어 발산부터 기술 검토, 기획 구체화, 최종 기능 명세서 작성에 이르기까지 기획-기술 연결 역할을 수행하였습니다.

### 1. 아이디어 발산 및 타당성 검토 기여
* **WebRTC 중심 10개 이상의 혁신 아이디어 제안:** 실시간 보이스피싱 탐지를 비롯하여 AI 기반 모자이크, 실시간 학습 코칭 등 다각도의 비즈니스 모델 및 연동 아키텍처 발산.
* **타 영역 아이디어 구체화 및 상세 기술 매핑:** * *비대면 중고거래 라이브 검증:* 실시간 녹화 영상 사후 업로드 및 AI 자동 문서화 프로세스 설계.
  * *디지털 트윈 쇼룸:* 원격 사용자의 체형 데이터 동기화 및 1:1 라이브 가상 피팅 흐름 구체화, 실시간 비디오 프레임에 대한 적용 방안 구체화.

### 2. 팀 협업 및 기획 고도화 기여
* **공동 회의록 작성 및 기술 싱크(Sync) 조율:** 팀 미팅 참여와 원활한 피드백을 위해 공동 회의 내용 및 아이디어별 차별점을 직관적으로 요약한 아카이브 정리본을 작성.
* **핵심 아키텍처 및 화면 설계(Mockup) 기획:** * *마네킹 피팅 스펙 다각화:* 2D 및 3D 마네킹 구현 방식에 따른 사용자 경험(UX)과 렌더링 오버헤드 간의 트레이드오프 고민 및  대안 제시.
  * *동시 송출 레이아웃 설계:* 동반 여행 참여자(최대 4인) 기준의 실시간 다중 영상 송출 목업 화면 및 인터랙션 아이디어 제안.

### 3. 최종 요구사항 명세서(SRS) 완결
* **세부 예외 처리 및 최종 플로우 명세:** 기능 명세서의 핵심인 'F-06-07 최종 결과 및 구매 이동' 단계를 직접 작성하여, 쇼핑몰 외부 링크 이동 시의 이탈 방지 UI 대체안, 추천 조건 복제 시의 예외 처리 정책 등을 최종 명세화함.


| **ID** | **우선순위** | **기능/동작** | **예외·정책** | **인수 조건 (AC)** |
| --- | --- | --- | --- | --- |
| **F-06-01** | P0 | • 티어메이킹/아바타 피팅을 통해 확정한 상위 1~3개 상품의 이미지, 정보 및 아바타 착용샷(2D)을 결과 화면에 표시한다.
• 정보의 신뢰성을 위해 '상품 정보 수집 기준 시각'을 화면 하단에 명시한다. | • 혼자 고르기 세션에서도 사용자가 최종 선택한 후보 상품(최대 3개)을 표시할 수 있도록 지원한다.
• 친구 닉네임 외 개인정보는 결과에 포함하지 않는다. | **AC1** 최종 결과 스냅샷과 티어표(또는 선택 리스트) 데이터가 일치한다.
**AC2** 결과 화면 새로고침 시에도 동일한 결과 세션이 유지된다.
**AC3** 결과 화면의 아바타 착용 이미지를 디바이스에 저장하거나 공유할 수 있다. |
| **F-06-02** | P0 | • 최종 선정된 1~3위 상품을 각각 구매할 수 있는 외부 판매처 링크를 제공한다. | • 서비스 내부 결제/장바구니 기능은 제공하지 않으며, 외부 링크는 새 창(Target="_blank")으로 연결한다. | **AC1** Route A(혼자), Route B(같이) 모두 복수 상품 구매 링크를 정상 제공한다.
**AC2** 연결된 외부 쇼핑몰 URL의 유효성을 검증한다.
**AC3** 모바일/웹 브라우저 팝업 차단 상태에서도 직접 이동할 수 있는 대체 버튼을 제공한다. |
| **F-06-03** | P0 | • '구매하러 가기' 클릭 시 외부 링크로 이동한다. | • "실시간 판매처 상황에 따라 가격 및 재고가 변동될 수 있습니다"라는 안내 문구를 시각적으로 노출한다.
• 로그 수집 시 사용자의 민감 정보는 마스킹 처리한다. | **AC1** 중복 클릭 시 로그가 비정상적으로 누적되지 않도록 디바운스(Debounce) 처리를 적용한다.
**AC2** 외부 링크 이동 실패 시 에러 알림을 띄우고 원래 결과 화면을 유지한다. |
| **F-06-04** | P1 | • 회원은 마이페이지 등에서 지난 추천 조건(TPO, 예산)을 확인하고, 이에 추천된 상품, 티어를 확인할 수 있다.  | • 복제 시 이전 추천에서 품절/만료된 상품은 제외하고, 현재 활성화된 상품들로 최신화하여 추천 API를 재호출한다.
• 저장된 사용자의 아바타 체형 정보는 그대로 유지된다. | **AC1** 이전 세션 복제 시 기존 입력 폼에 조건값들이 자동으로 바인딩된다.
**AC2** 복제된 새 세션에서 일부 조건(예: 예산 변경 등)만 수정하여 다시 추천받는 흐름이 정상 작동한다. |
