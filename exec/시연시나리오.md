# 소개팅 의상 티어메이킹 시연 시나리오

## 시연 구성

| 역할 | 담당 |
| --- | --- |
| 방장 | A |
| 참여자 | B, C |
| 시연 주제 | 소개팅에 입을 니트와 바지를 함께 고르고 아바타 피팅 결과를 확인한다. |

## 사전 준비

- A, B, C는 각자 계정을 미리 회원가입해 둔다.
- A는 체형 설정과 로그인에 사용할 본인 계정을 준비한다.
- B, C는 초대 링크를 받을 수 있도록 MM을 실행해 둔다.

## 시연 진행

| 순서 | 진행자 | 화면·조작 | 시연 멘트 |
| --- | --- | --- | --- |
| 1 | A | 메인 페이지에서 본인 계정으로 로그인한다. | “소개팅 옷을 같이 골라볼게요.” |
| 2 | A | **맞춤형 체형 설정하기**를 선택하고 체형 정보를 설정한다. | “먼저 제 체형에 맞는 추천을 받도록 설정할게요.” |
| 3 | A | 메인 페이지에서 **지금 시작하기**를 클릭한다. |  |
| 4 | A | 의상 추천을 받은 뒤 **티어메이커 시작하기**를 선택한다. | “추천받은 옷들로 티어메이킹을 시작해 볼게요.” |
| 5 | A | 추천 조건을 입력한다. | “상의, 니트, 0~10만 원, 로맨틱 무드로 볼게요. 장소는 실내 레스토랑 소개팅입니다.” |
| 6 | A | MM으로 초대 링크를 B, C에게 보낸다. | “나 이번에 소개팅 하는데 내 옷 좀 골라줘.” |
| 7 | B, C | MM에서 답장한 뒤 초대 링크로 입장한다. | B, C: “ㅇㅋ 가자.” |
| 8 | A, B, C | 티어메이킹 대기실에서 B, C의 입장을 확인하고 참여자를 모집한다. | A: “다 모였으니 시작할게.” |
| 9 | A | 참여자가 모두 모이면 **티어메이킹 시작**을 클릭한다. |  |

## 보드 협업 및 피팅

| 순서 | 진행자 | 화면·조작 | 시연 멘트 |
| --- | --- | --- | --- |
| 10 | A | 티어메이킹 보드에서 대화를 시작한다. | “ㅎㅇ 나 이번에 소개팅 하는데 내 옷 좀 골라줘.” |
| 11 | B | 의상 1을 **S 랭크**로 올린다. | “아, 이번에 이거 입고 가자.” |
| 12 | C | 의상 1을 **B 랭크**로 내리고, 의상 2를 **S 랭크**로 옮긴 뒤 마우스로 잡고 있는 상태를 보여 준다. | “아님, 그거보다 이거야.” |
| 13 | A | 의상 2를 다시 잡으려 시도해 잠금 상태로 이동할 수 없음을 보여 준다. | “아 그래?? 난 이거 마음에 안 드는데. 그거 잠시만 놔봐.” |
| 14 | C | 의상 2를 계속 잡은 상태를 유지한다. | “아니야, 이거 입어야 돼.” |
| 15 | C | 의상 2를 **피팅 후보**로 옮긴다. | “그러면 입어보고 결정하자.” |
| 16 | B | 어울리는 바지를 **피팅 전용 보관함**에 추가한 뒤 피팅 후보로 옮긴다. | “어울리는 바지랑 같이 입어보자. 이거랑 입어봐!” |
| 17 | A | 피팅 후보의 상·하의를 확인하고 사이즈 및 착장 방식을 조절한다. | “그럼 이거 사이즈는 이렇게 해서 입어볼게. 이건 넣어입는 게 나으려나?” |
| 18 | B | 착장 방식에 의견을 준다. | “이건 넣어입자.” |
| 19 | A | 선택한 코디로 **아바타 생성**을 실행한다. | “그래, 그럼 이걸로 아바타 생성해 볼게.” |
| 20 | A | 이미지 생성이 완료되면 피팅 결과를 확인한다. | “어, 이거 괜찮은데?” |

## 종료 및 결과 확인

| 순서 | 진행자 | 화면·조작 | 시연 멘트 |
| --- | --- | --- | --- |
| 21 | A | 최종 코디를 결정하고 보드 종료를 알린다. | “그럼 이걸로 시켜야겠다. 방 종료할게, 같이 골라줘서 고마워.” |
| 22 | B, C | 종료 인사를 한다. | “ㅇㅇ 잘 갔다와~” |
| 23 | A | **보드 종료**를 클릭한다. |  |
| 24 | A | 종료 후 표시되는 티어메이킹 결과 화면에서 최종 랭킹과 선택한 피팅 결과를 확인한다. | “함께 고른 티어메이킹 결과를 확인할 수 있습니다.” |

## 시연 핵심 포인트

- 체형 기반 의상 추천부터 조건 필터링, 티어메이킹 생성까지의 흐름
- 링크 초대를 통한 다중 사용자 입장과 대기실 참여자 모집
- 동시 드래그 시 의상 이동이 잠기는 실시간 협업 경험
- 피팅 후보·전용 보관함 활용, 사이즈·착장 방식 조절 및 아바타 이미지 생성
- 보드 종료 후 최종 티어메이킹 결과 확인
